# Barbearia Premium

Site demonstrativo premium para barbearia, com identidade visual sofisticada, navegação responsiva, galeria, equipe, serviços, avaliações editáveis e solicitação de agendamento pelo WhatsApp.

## Demo

- Vercel: https://barbearia-premium-rho-nine.vercel.app
- Sites: https://barbearia-premium-winc.jujuliansousa5.chatgpt.site

## Personalização

Os principais dados do projeto ficam centralizados no objeto `siteConfig`, dentro de `dist/index.html`:

- Nome da barbearia
- Telefone e WhatsApp
- Endereço, mapa e rota
- Instagram
- Serviços, preços e duração
- Equipe
- Galeria
- Avaliações
- Horários disponíveis
